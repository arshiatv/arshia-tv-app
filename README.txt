لوگو و اسپلش آرشیا تی‌وی
========================
جایگزین کن:

assets/icon.png           → آیکون اپ (ARIYATV طلایی/قرمز) ۱۰۲۴
assets/adaptive-icon.png  → آیکون اندروید (با حاشیه امن)
assets/favicon.png        → وب
assets/splash.png         → صفحه شروع تمام‌صفحه (لوگو ARSHIA TV کره) روی #0A0E17
assets/splash-landscape.png → اختیاری برای TV افقی
assets/icon-arshia.png    → نسخه جایگزین با لوگوی کره

app.json → مسیرها و رنگ پس‌زمینه اسپلش

بعد از کپی: بیلد جدید بگیر تا آیکون/اسپلش اعمال شود.
